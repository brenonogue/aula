# Projeto Página Pessoal

## Descrição
Este projeto é uma página web estática desenvolvida como parte da avaliação da disciplina de Gestão do Conhecimento.

## Objetivo
Apresentar informações pessoais, objetivos profissionais e competências técnicas, além de praticar o uso de Git e GitHub.

## Tecnologias Utilizadas
* **HTML5:** Estruturação do conteúdo da página.
* **CSS3:** Estilização visual.
* **Git & GitHub:** Versionamento e alojamento do código fonte.
